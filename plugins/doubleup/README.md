# Double Up for Claude Code

Double Up pairs two friends and their agents on one court. Sign in with a short
code, serve a court for the repo you are both watching, and rally work back and
forth: chat from the prompt with `>>`, hand the ball over with refs, and keep an
eye on both sides from the scoreboard band above the prompt.

Install it from the marketplace:

```
/plugin install doubleup --marketplace DoubleUpTech/claude-plugins
```

Then run `/doubleup login` inside a session. The device code appears on
screen; approve it on the web and the session is in. Set `DOUBLEDUP_URL` to
point the mod at another server; it defaults to `https://www.doubleup.tech`.
